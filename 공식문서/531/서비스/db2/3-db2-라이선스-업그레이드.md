## 원문 전문

Upgrading the license before you deploy Db2
Last Updated: 2026-03-26

After you install the Db2 service, you can upgrade your
license from Db2 Community Edition to Db2 Advanced Edition.

### About this task

Community Edition 라이선스를 Db2 12.1 프로덕션 라이선스로
업그레이드 가능:

| Db2 edition | Processor cores | Allowed instance memory |
|---|---|---|
| Advanced | Unlimited | Unlimited |
| Standard | Up to 16 | 128 GB |
| Community | Up to 4 | 16 GB |

라이선스 키는 IBM Passport Advantage 에서 다운:
- Db2 Advanced Edition: db2adv_vpc.lic
- Db2 Standard Edition: db2std_vpc.lic

Note: 라이선스 사용 권한(구매)이 있어야 다운 가능.

### Procedure

1. 라이선스를 Base64 인코딩해 환경변수로:
```bash
base64 license.lic | tr -d '\n' > /tmp/encode.lic
export license=$(cat /tmp/encode.lic)
```

2. (선택) secret 키·이름 환경변수:
```bash
export secretKeyName=<SecretKeyNameValue>
export secretName=<secretNameValue>
```
   ※값은 Kubernetes Object Names 규칙 준수.

3. (선택) secret 생성 (1의 라이선스 + 2의 secret):
```yaml
apiVersion: v1
data:
  ${secretKeyName}: ${license}
kind: Secret
metadata:
  name: ${secretName}
  namespace: ${PROJECT_CPD_INST_OPERANDS}
type: Opaque
```

4. licenseType 지정:
```bash
export licenseType=<licensetype>
# <licensetype> = Advanced 또는 Standard
```

5. Db2oltpservice 를 라이선스 정보로 patch:
```bash
# secret 만든 경우 (step 3):
oc patch Db2oltpservice db2oltp-cr -n ${PROJECT_CPD_INST_OPERANDS} --type merge -p "{\"spec\":{\"license\":{\"license\":\"${licenseType}\",\"licenseValue\":{\"valueFrom\":{\"secretKeyRef\":{\"key\":\"${secretKeyName}\",\"name\":\"${secretName}\"}}}}}}"

# secret 안 만든 경우:
oc patch Db2oltpservice db2oltp-cr -n ${PROJECT_CPD_INST_OPERANDS} --type merge -p "{\"spec\":{\"license\":{\"license\":\"${licenseType}\",\"licenseValue\":{\"value64\":\"${license}\"}}}}"
```

6. Db2 서비스가 Completed 될 때까지 대기:
```bash
oc get Db2oltpService db2oltp-cr -n ${PROJECT_CPD_INST_OPERANDS} -o jsonpath='{.status.db2oltpStatus} {"\n"}'
```

## 우리 사전확인 (STEP 19 전) `[은정님 정리]`

```bash
# ① Db2 서비스 라이선스 에디션 확인
oc get db2oltpservice db2oltp-cr \
  -n ${PROJECT_CPD_INST_OPERANDS} -o json | jq '.spec.license'
#  → Community 면 이 절차 해당 없음
#  → Standard/Advanced 면 12.1 라이선스 키 챙겨 절차 수행

# ② 실제 Db2 인스턴스 종류·목록
oc get db2ucluster,db2uinstance -n ${PROJECT_CPD_INST_OPERANDS}

# ③ 고객 확인: Community 그대로인가 / Standard·Advanced 구매·적용했나
#    (No.72 결정대기 — 발주처 계약 사항)
```
