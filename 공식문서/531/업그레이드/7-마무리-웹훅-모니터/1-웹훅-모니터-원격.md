## 1. 웹훅 (Upgrading the configuration admission controller webhook)

설치돼 있을 때만. 사설 레지스트리면 ZEN_VERSION 지정 필요:
```bash
${CPDM_OC_LOGIN}
export ZEN_VERSION=6.4.11   # ★5.3.1 Patch 12 짝 (위 표)
# install-cpd-config-ac (사설 변형 — 본문 접힘 미노출) 후:
cpd-cli manage enable-cpd-config-ac \
--cpd_instance_ns=${PROJECT_CPD_INST_OPERANDS}
```

## 2. 특권 모니터 (Upgrading privileged monitors)

설치돼 있을 때만 — 별도 프로젝트에 클러스터당 1회 설치되는 구조.
`apply-privileged-monitoring-service` 로 업그레이드
(오퍼레이터 프로젝트만 / +스케줄러 프로젝트 포함 두 변형 — 본문 접힘).

## 3. 원격 물리 로케이션 (Upgrading remote physical locations)

허브(주 인스턴스) 업그레이드 후, 연결된 원격 로케이션의
공유 컴포넌트→에이전트→서비스 SW 순 갱신 (하위 3장).
★모비스 = 단일 클러스터, 원격 로케이션 없음 → 통째 해당 없음 [확정]
