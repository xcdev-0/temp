## Before you begin[](https://www.ibm.com/docs/en/software-hub/5.3.x?topic=hub-updating-cluster-scoped-resources-instance#taskcrds__prereq__1 "Copy to clipboard")

Best practice: You can run the commands in this task exactly as written if you use your installation environment variables script.

Ensure that you source the environment variables before you run the commands in this task.

## About this task[](https://www.ibm.com/docs/en/software-hub/5.3.x?topic=hub-updating-cluster-scoped-resources-instance#taskcrds__context__1 "Copy to clipboard")

Use the `cpd-cli manage case-download` command to generate cluster-scoped resources for components that support Helm-based installation and upgrade.

Restriction: If a component does not support Helm-based installation, the command does not generate any cluster-scoped resources.

The command generates a YAML file named `cluster_scoped_resources.yaml` that defines the following resources for each component that you plan to upgrade:

- CRDs
- Cluster roles
- Cluster role bindings
- Webhooks, if applicable

Some resources, such as CRDs, are applied to the cluster exactly once. Other resources, such as cluster role bindings must be applied to the operator project for each instance of IBM Software Hub that you plan to upgrade.

After you review the YAML files, use the `cluster_scoped_resources.yaml` file to apply the resources to the cluster.

## Procedure[](https://www.ibm.com/docs/en/software-hub/5.3.x?topic=hub-updating-cluster-scoped-resources-instance#taskcrds__steps__1 "Copy to clipboard")

1. Generate the `cluster_scoped_resources.yaml` file.
    
    The command requires the `CASE` packages to be on the workstation. Run the appropriate command for your environment:
    
    ---
    
    The CASE packages are already on the client workstation
    
    ```bash
    cpd-cli manage case-download \
    --components=${COMPONENTS} \
    --release=${VERSION} \
    --patch_id=${PATCH_ID} \
    --operator_ns=${PROJECT_CPD_INST_OPERATORS} \
    --cluster_resources=true
    ```
    
    ---
    
    Download the CASE package from GitHub (github.com/IBM)
    
    ---
    
    Download the CASE package from the IBM Cloud Pak Open Container Initiative repository
    
    ---
    
    Download the CASE packages from your own Open Container Initiative repository
    
    ---
    
2. Change to the `work` directory.
    
    The default location of the `work` directory is `cpd-cli-workspace/olm-utils-workspace/work`.
    
3. Log in to Red Hat® OpenShift® Container Platform as a cluster administrator.
    
    ```bash
    ${OC_LOGIN}
    ```
    
    Remember: `OC_LOGIN` is an alias for the `oc login` command.
    
4. Apply the cluster-scoped resources for the from the cluster_scoped_resources.yaml file:
    
    ```bash
    oc apply -f cluster_scoped_resources.yaml \
    --server-side \
    --force-conflicts
    ```
    
5. Optional: If you want a record of the resources that you generated, rename the `cluster_scoped_resources.yaml`
    
    ```bash
    mv cluster_scoped_resources.yaml ${VERSION}-${PROJECT_CPD_INST_OPERATORS}-cluster_scoped_resources.yaml
    ```
