## 본문 요지

- License Service 가 라이선스 조건 대비 사용량을 계량 — apply-entitlement 로
  "이 인스턴스에 어떤 라이선스가 적용되는지" 알려주는 작업
- required 조건: 설치 때 안 했거나 / 솔루션 구성 변경 시
- 절차: ${CPDM_OC_LOGIN} → 설치된 솔루션별로 apply-entitlement 반복
  (production=true/false 변형) → 제거 예정 솔루션은 remove-entitlement
- 명령 골격:
```bash
cpd-cli manage apply-entitlement \
--cpd_instance_ns=${PROJECT_CPD_INST_OPERANDS} \
--entitlement=${LICENSE_NAME} \
--production=true
```
- 라이선스 목록: CPD EE/SE·Cognos·DataStage·IKC·OpenPages·Speech·
  wx.ai·wx.data·wx.governance·wxO 등 25종 (모비스 = CPD 에디션 계열 추정)

## 하위 b — 노드피닝판 (9/2 수집, 요지만)

- 조건: 솔루션 변경 + 노드피닝 사용(또는 시작) — 둘 다 참일 때만.
  ★모비스 노드피닝 미사용 추정 → 해당 없음 [실측: 노드에
  isc-entitlement 라벨 존재 여부로 판별 가능]
- 노드피닝 = 유료(chargeable) 파드를 특정 노드에 고정해 라이선스
  준수를 보장하는 방식. 식별은 호스트명 또는 라벨(isc-entitlement=값),
  강제 여부는 required/preferred DuringScheduling 설정으로 갈림
- 명령은 apply-entitlement 에 피닝 변수들이 추가되는 형태
  (본문 명령 블록은 페이지 접힘으로 미노출 — 필요 시 재수집)
