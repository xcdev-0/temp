## 본문 요지 + 명령 (전문 보존)

Editing your environment variables file:

1. VERSION 갱신:
```bash
export VERSION=5.3.1
```
2. OLM_UTILS_IMAGE (라이선스·아키별):
```bash
# 표준 (전 고객) — x86-64
export OLM_UTILS_IMAGE=icr.io/cpopen/cpd/olm-utils-v4:${VERSION}.amd64
# (ppc64le / s390x 접미 변형 존재)
# 프리미엄 라이선스 구매 시: cp.icr.io/cp/cpd/olm-utils-premium-v4:${VERSION}.amd64
```
   Tip: 사설 레지스트리 클러스터는 push 후에 이 변수를 갱신한다
3. COMPONENTS 확인 (정확한지)
4. 모델·선택 이미지 미러 시:
```bash
export IMAGE_GROUPS=<comma-separated-list-of-group-names>
```
   (기본 미러에 안 딸려오는 모델·선택 이미지는 명시적으로 미러
    — 예: watsonx.ai 모델 선택. 상세는 ⓪-b 문서)
5. Image pull configuration 절 추가:
```bash
export IMAGE_PULL_SECRET=<pull-secret-name>
# 사설 레지스트리 클러스터 (export 명령 수정 금지):
export IMAGE_PULL_CREDENTIALS=$(echo -n "$PRIVATE_REGISTRY_PULL_USER:$PRIVATE_REGISTRY_PULL_PASSWORD" | base64 -w 0)
export IMAGE_PULL_PREFIX=${PRIVATE_REGISTRY_LOCATION}
# (Entitled Registry 클러스터는 cp:$IBM_ENTITLEMENT_KEY / icr.io)
```
6. 저장 → 문법 검사:
```bash
bash ./cpd_vars.sh
```

Sourcing: 명령 실행 전 반드시 `source ./cpd_vars.sh` —
★새 bash 프롬프트를 열 때마다 재실행 (Important)
