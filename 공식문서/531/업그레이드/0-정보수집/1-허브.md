## 본문 (전문)

To successfully upgrade your IBM Software Hub installation, you must have
specific information about your environment.

Who needs to complete this task?
- Operations team — determine: which components are installed on the cluster /
  which components are associated with the instance you want to upgrade.

When do you need to complete this task?
- Repeat as needed — repeat for each instance of IBM Software Hub.
- Ensure that you complete this task before you:
  - Mirror images to your private container registry
  - Prepare to upgrade an instance of IBM Software Hub

Procedure — complete the following tasks:
1. Determining which components to upgrade (5.1→5.3) — determine which
   components are installed for the instance you want to upgrade.
2. Determining which models and images to mirror to your private container
   registry — if you use a private registry, you might need to mirror
   additional images and models (such as foundation models) depending on
   the services you plan to upgrade and features you plan to enable.
3. Updating your environment variables script — commands use ${VARIABLE_NAME}
   variables; ensure your script has correct information for the instance.
