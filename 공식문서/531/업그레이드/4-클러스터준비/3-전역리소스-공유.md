## 본문 요지 + 명령

전제: 환경변수 source. CASE 가 워크스테이션에 있어야 함.

1. 스케줄러용 전역 리소스 yaml 생성 (CASE 로컬 존재 시 — 폐쇄망 OK):
```bash
cpd-cli manage case-download \
--components=scheduler \
--release=${VERSION} \
--patch_id=${PATCH_ID} \
--scheduler_ns=${PROJECT_SCHEDULING_SERVICE} \
--cluster_resources=true
```
(GitHub/OCI/자체 OCI 저장소 변형 동일 구조)
2. work 디렉토리로 이동 (기본 cpd-cli-workspace/olm-utils-workspace/work)
3. ${OC_LOGIN}
4. 적용:
```bash
oc apply -f cluster_scoped_resources.yaml \
--server-side \
--force-conflicts
```
5. (선택) 기록용 개명:
```bash
mv cluster_scoped_resources.yaml ${VERSION}-${PROJECT_SCHEDULING_SERVICE}-cluster_scoped_resources.yaml
```
