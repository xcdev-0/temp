# Creating image pull secrets for shared cluster components (Upgrading from Version 5.1 to Version 5.3)

Last Updated: 2026-07-15

If the scheduling service is installed on the cluster, you must create an image pull secret in the project where you plan to install the scheduling service. The image pull secret ensures that the scheduling service has access to the credentials for pulling images.

Who needs to complete this task?

Cluster administrator A cluster administrator must complete this task.

When do you need to complete this task?

Complete this task if the scheduling service is installed on the cluster.

You must create the image pull secret before you upgrade the scheduling service.

One-time setup Complete this task once for each cluster where you plan to upgrade the IBM® Software Hub scheduling service.

## Before you begin[](https://www.ibm.com/docs/en/software-hub/5.3.x?topic=pyc-creating-image-pull-secrets-shared-cluster-components#taskshared-component-secrets__prereq__1 "Copy to clipboard")

Best practice: You can run the commands in this task exactly as written using the installation environment variables. Ensure that you added the new environment variables from [Updating your environment variables script](https://www.ibm.com/docs/en/SSNFH6_5.3.x/hub/upgrade/v51/collect-info-install-variables.html).

In addition, ensure that you source the environment variables before you run the commands in this task.

## About this task[](https://www.ibm.com/docs/en/software-hub/5.3.x?topic=pyc-creating-image-pull-secrets-shared-cluster-components#taskshared-component-secrets__context__1 "Copy to clipboard")

## Procedure[](https://www.ibm.com/docs/en/software-hub/5.3.x?topic=pyc-creating-image-pull-secrets-shared-cluster-components#taskshared-component-secrets__steps__1 "Copy to clipboard")

1. Log in to Red Hat® OpenShift® Container Platform as a user with sufficient permissions to complete the task.
    
    ```bash
    ${OC_LOGIN}
    ```
    
    Remember: `OC_LOGIN` is an alias for the `oc login` command.
    
2. Create a file named `dockerconfig.json` based on where your cluster pulls images from:
    
    ---
    
    IBM Entitled Registry
    
    ```bash
    cat <<EOF > dockerconfig.json 
    {
      "auths": {
        "cp.icr.io": {
          "auth": "${IMAGE_PULL_CREDENTIALS}"
        },
        "icr.io":{
          "auth": "${IMAGE_PULL_CREDENTIALS}"
        }
      }
    }
    EOF
    ```
    
    ---
    
    Private container registry
    
    ```bash
    cat <<EOF > dockerconfig.json 
    {
      "auths": {
        "${PRIVATE_REGISTRY_LOCATION}": {
          "auth": "${IMAGE_PULL_CREDENTIALS}"
        }
      }
    }
    EOF
    ```
    
    ---
    
3. Create the image pull secret in the project where the scheduling service is installed:
    
    ```bash
    oc create secret docker-registry ${IMAGE_PULL_SECRET} \
    --from-file ".dockerconfigjson=dockerconfig.json" \
    --namespace=${PROJECT_SCHEDULING_SERVICE}
    ```
