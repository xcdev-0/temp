## 본문 (전문)

Before you can upgrade, ensure the workstation has supported versions of:
the IBM Software Hub CLI (cpd-cli), the OpenShift CLI (oc), and the Helm CLI.

Who: All administrators — any user involved in upgrading needs access to
a client workstation with supported CLI versions.
When: Repeat as needed — at least one workstation, repeat for multiple.

Procedure:
1. Updating the IBM Software Hub CLI — correct version of cpd-cli and
   the olm-utils-v4 image.
2. Updating the OpenShift CLI — oc version compatible with your cluster.
3. Installing the Helm CLI — to make it easier to debug upgrade issues.
