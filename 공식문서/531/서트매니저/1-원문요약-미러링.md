## 절차 요지

전제: Red Hat pull secret + oc-mirror v2 플러그인

```bash
CLUSTER_CONFIGS_DIR=<fully-qualified-path>
export OPENSHIFT_VERSION=v4.18   # 모비스 값
```

red-hat-cert-manager.yaml:
```yaml
kind: ImageSetConfiguration
apiVersion: mirror.openshift.io/v2alpha1
mirror:
  operators:
    - catalog: registry.redhat.io/redhat/redhat-operator-index:${OPENSHIFT_VERSION}
      packages:
      - name: openshift-cert-manager-operator
```

미러 (원문 — ⚠`c` 는 `-c` 의 오타):
```bash
oc mirror -c red-hat-cert-manager.yaml \
--workspace file://${CLUSTER_CONFIGS_DIR} \
docker://${PRIVATE_REGISTRY_LOCATION} --v2
```

산출: working-dir/cluster-resources 에
ImageDigestMirrorSet / ImageTagMirrorSet / CatalogSource

적용(현장):
```bash
oc apply -f ${CLUSTER_CONFIGS_DIR}/working-dir/cluster-resources
oc get imagedigestmirrorset
oc get catalogsource -n openshift-marketplace
```
